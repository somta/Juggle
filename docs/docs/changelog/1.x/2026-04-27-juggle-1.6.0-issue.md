# 1.6.0版本 - 2026/04/27
该版本主要修复了一些新的bug,优化交互逻辑，全面升级了后端服务框架版本，并支持虚拟线程处理，提升处理能力。
变更详情：

### Feature

● 后端服务全面升级，框架升级到springboot 3.x,jdk升级到21

### Enhancement&Refactor

● 全面使用虚拟线程，同样配置下处理能力大幅提升

### BugFix

● 调整流程试运行的超时时间，解决大模型返回较慢时的超时问题

● 非必填参数为空时，反序列化为空字符串的问题

● mysql节点输入大数字时，会默认加上逗号的问题
