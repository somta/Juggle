# 1.7.0版本 - 2026/08/27
该版本主要修复了一些新的bug,优化交互逻辑，全面升级了后端服务框架版本，并支持虚拟线程处理，提升处理能力。
变更详情：

### Feature

● 添加修改管理员密码能力

● 优化整个系统的交互体验和主题色，去掉面包屑

● 接口调试对象支持json输入

● 重构接口调试页面，提供更方便的操作页面

● 扩大套件图片上传的大小限制


### BugFix

● 去掉多个数据源的实现，统一交给spring管理，避免多数据源实例不一致的问题

● 修复套件管理中，判断操作结果的字段错误的问题

● 修复套件类型错误的问题

● 套件安装添加套件编码校验，避免重复安装
